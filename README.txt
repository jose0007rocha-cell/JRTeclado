JR Teclado - teclado Android estilo Yandex

Como gerar o APK:
1. Crie um repositorio no GitHub e envie TODOS os arquivos desta pasta (inclusive a pasta .github).
2. Aba Actions > "Build APK" > aguarde terminar.
3. Baixe o artefato "JRTeclado-apk" (dentro vem o app-debug.apk).

Depois de instalar: abra o app JR Teclado, toque em "Ativar teclado" e "Selecionar teclado".
No teclado, o icone de engrenagem abre as configuracoes (Temas, Aparencia, Som, Fontes, Flutuante).
